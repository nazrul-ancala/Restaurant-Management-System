# Domain Model

## Overview

The Restaurant Management System consists of several business domains that work together to support the daily operations of a restaurant.

This document describes the core business entities, their responsibilities, states, and interactions before translating them into a database design.

---

# Employee

## Description

An Employee is a staff member who operates the restaurant system.

## Roles

- Administrator
- Manager
- Waiter
- Chef
- Cashier

## Responsibilities

Administrator

- Manage employee accounts
- Configure system settings

Manager

- Manage menu
- Manage inventory
- View reports
- Record food waste

Waiter

- Assign tables
- Create customer orders
- Update customer requests

Chef

- View kitchen orders
- Update cooking status
- Report cooking mistakes

Cashier

- Process payments
- Generate receipts

---

# Customer

## Description

Represents a customer purchasing food.

Customer information is optional for dine-in orders but recommended for takeaway orders.

## Attributes

- Name (Optional)
- Phone Number (Optional)

---

# Table

## Description

Represents a physical dining table inside the restaurant.

## Attributes

- Table Number
- Capacity

## Status

- Available
- Occupied
- Reserved
- Cleaning

---

# Order

## Description

Represents a customer's food purchase.

An order belongs to one customer session.

## Order Types

- Dine-In
- Takeaway

## Status Flow

Pending

↓

Preparing

↓

Ready

↓

Served (Dine-In Only)

↓

Completed

Cancelled may occur before Completed.

## Contains

- One or more Order Items
- Payment Information

---

# Order Item

## Description

Represents an individual menu item within an order.

Example

Order #102

- Chicken Chop
- Coke
- Salad

Each menu item is stored as a separate Order Item.

---

# Menu Category

## Description

Groups menu items into categories.

Examples

- Appetizers
- Main Course
- Dessert
- Drinks

---

# Menu Item

## Description

Represents food or beverages available for sale.

## Attributes

- Name
- Price
- Availability

Availability

- Available
- Sold Out
- Hidden

Each Menu Item references one Recipe.

---

# Recipe

## Description

Defines the ingredients required to prepare one Menu Item.

Example

Chicken Burger

- Bun
- Chicken Patty
- Lettuce
- Cheese
- Sauce

The recipe determines inventory deduction after order completion.

---

# Inventory Item

## Description
Inventory stores the current stock level.

Stock history is maintained by Stock Movement records.

Represents ingredients or stock used to prepare menu items.

Examples

- Chicken Breast
- Rice
- Tomato
- Cheese
- Coke Can

## Attributes

- Name
- Current Stock
- Minimum Stock
- Unit

## Supported Units

- Piece
- Gram
- Kilogram
- Milliliter
- Liter
- Bottle
- Can
- Pack

---

# Supplier

## Description

Represents vendors supplying inventory items.

Examples

- Fresh Farm Supplier
- Beverage Distributor

Responsibilities

- Supply inventory
- Restock ingredients

---

# Waste Record

## Description

Represents inventory lost due to operational issues.

Creating a Waste Record generates a Waste Stock Movement.

## Reasons

- Burnt Food
- Wrong Order
- Expired Ingredient
- Damaged Ingredient
- Customer Complaint

Recording waste allows managers to monitor kitchen efficiency.

---

# Payment

## Description

Represents payment for an order.

## Payment Methods

- Cash
- Credit/Debit Card
- QR Payment

## Status

- Pending
- Paid
- Refunded

---

# Audit Log

## Description

Records important actions performed in the system.

Examples

- Employee Login
- Menu Price Updated
- Order Cancelled
- Inventory Adjusted
- Waste Recorded
- Payment Completed

---

# Business Relationships

The following relationships exist between the business entities.

Employee

- Creates Orders
- Updates Order Status
- Processes Payments

Customer

- Places Orders

Order

- Contains Order Items
- Has One Payment
- Uses One Order Type

Order Item

- References One Menu Item

Menu Item

- Belongs to One Category
- Uses One Recipe

Recipe

- Uses Multiple Inventory Items

Inventory Item

- Supplied By Supplier
- Consumed By Recipes

Waste Record

- References Inventory Items

Audit Log

- Records Activities Across The Entire System


# Stock Movement

## Description

Represents every increase or decrease of inventory.

It acts as the audit trail for all inventory transactions.

## Movement Types

- Purchase
- Sale
- Waste
- Adjustment
- Return

## Generated By

- Completed Orders
- Waste Records
- Supplier Deliveries
- Inventory Adjustments

## Responsibilities

- Update inventory quantity
- Record movement history
- Support inventory reporting
